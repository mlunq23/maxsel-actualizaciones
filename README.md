# Maxsel POS — actualizaciones

Aquí se publican las versiones nuevas de **Maxsel POS**, **Maxsel POS Nube**, **Maxsel Hotel**, **Maxsel Motel** **Maxsel Gimnasios**, **Maxsel Tech** y **Maxsel Abarrotes** para que se instalen desde la app (Maxsel POS: Ajustes → Actualizaciones · Maxsel Hotel y Maxsel Motel: Configuración → Respaldos y licencia → Buscar actualización · Maxsel Gimnasios: Configuración → Actualizaciones · Maxsel Tech: Configuración → Actualizaciones; su información está en `maxsel-tech/version.json` · Maxsel Abarrotes: Configuración → Sistema → Buscar actualización; su información está en `maxsel-abarrotes/version.json`, firmada por Maxsel, y el instalador está en `maxsel-abarrotes/Instalar Maxsel Abarrotes.exe`).

- `version.json`: la versión más reciente y la huella SHA-256 de cada archivo (la app la revisa antes de instalar).
- APK de Android y paquetes de actualización para Windows.

Los programas solo funcionan con una licencia de Maxsel Sistemas de Punto de Venta · WhatsApp 664 337 5433.
