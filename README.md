# Maxsel POS — actualizaciones

Aquí se publican las versiones nuevas de **Maxsel POS**, **Maxsel POS Nube**, **Maxsel Hotel**, **Maxsel Motel** **Maxsel Gimnasios** y **Maxsel Tech** para que se instalen desde la app (Maxsel POS: Ajustes → Actualizaciones · Maxsel Hotel y Maxsel Motel: Configuración → Respaldos y licencia → Buscar actualización · Maxsel Gimnasios: Configuración → Actualizaciones · Maxsel Tech: Configuración → Actualizaciones; su información está en `maxsel-tech/version.json`).
