# Maxsel POS — actualizaciones

Aquí se publican las versiones nuevas de **Maxsel POS**, **Maxsel POS Nube** y **Maxsel Hotel** para que se instalen desde la app (Maxsel POS: Ajustes → Actualizaciones · Maxsel Hotel: Configuración → Respaldos y licencia → Buscar actualización).

- APK de Android y paquetes de actualización para Windows.
